# Tingbao Starbridge Adventure

請幫我建立一個繁體中文的 2D Q 版冒險遊戲，名稱是《星星失物招領所：給婷寶的星光》。

這是一份送給我在香港的好朋友婷寶的生日禮物。我在英國，她在香港，我們曾經一起去法國旅行。

遊戲需要有可操作的 2D 角色、方向鍵或 WASD 移動、手機觸控操作、收集星星、NPC 對話、關卡進度、寶箱動畫及生日結局。

請採用精緻可愛的少女系 Q 版像素遊戲風格。我的角色是中長深啡色頭髮、溫柔日系穿搭；婷寶是長深啡色頭髮、韓系時尚穿搭。

故事由星星失物招領所開始，經歷冒險和法國旅行回憶，最後讓兩個角色在連接英國與香港的星光橋上相遇，播放生日祝福及溫馨結局。

請先建立一個可以實際操作的遊戲原型，所有主要按鈕都要能使用。使用繁體中文，不要加入登入系統或付費 API。
